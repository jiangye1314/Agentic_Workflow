# Human Review Checklist

## 基本信息

- 案例名称：
- 输出编号：
- 审核人：
- 审核日期：

## 是否必须人工复核

- [ ] 医疗、法律、金融、招聘、教育未成年人数据
- [ ] 涉及企业敏感数据或商业机密
- [ ] 涉及支付、退款、合同、生产安全等高影响动作
- [ ] 模型置信度低
- [ ] 引用缺失或来源冲突

## 内容检查

- [ ] 输出是否回答了用户问题
- [ ] 事实是否有来源
- [ ] 是否存在夸大或绝对承诺
- [ ] 是否遗漏关键限制条件
- [ ] 是否需要补充免责声明或适用边界

## 安全检查

- [ ] 是否暴露个人信息
- [ ] 是否越权访问数据
- [ ] 是否包含不应执行的操作建议
- [ ] 是否需要转人工或升级审批

## 结论

- [ ] 通过
- [ ] 修改后通过
- [ ] 拒绝发布
- [ ] 转专业人员复核
