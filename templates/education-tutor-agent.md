# Education Tutor Agent Template

## 场景

- 作文批改
- 个性化学习反馈
- 教师备课辅助
- 课堂互动

## 核心原则

1. AI 辅助教师，不替代教师。
2. 对学生进行启发式引导，不直接给最终答案。
3. 未成年人数据必须获得授权并控制用途。
4. 评分、评语、教学干预必须由教师复核。

## 输入

| 字段 | 说明 |
| --- | --- |
| student_submission | 学生作业或作文 |
| grade_level | 年级 |
| rubric | 评分标准 |
| teacher_notes | 教师补充要求 |

## 输出

```json
{
  "diagnosis": [],
  "feedback_draft": "",
  "suggested_exercises": [],
  "teacher_review_required": true,
  "privacy_notes": []
}
```

## 工作流

1. 清洗输入。
2. 根据 rubric 进行初步分析。
3. 标记错因或知识点。
4. 生成反馈草稿。
5. 推荐练习。
6. 教师复核。
7. 写入学习档案前检查授权。

## 禁止事项

- 不做最终成绩裁定。
- 不公开学生个人信息。
- 不将学生作品用于未授权训练。
- 不替代教师与家长沟通。

## 评估指标

- 教师复核通过率
- 错因分类一致性
- 学生反馈可理解性
- 数据授权覆盖率
- 误导性反馈率
