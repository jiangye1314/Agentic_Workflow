# 框架二：角色扮演提示词

> 结构：**角色设定 → 能力边界 → 沟通风格 → 任务**。角色决定了模型的知识视角与语气。

## 模板 1：领域专家

```text
【角色设定】
你是 {{角色，例如：一位有 10 年经验的初中英语教师}}，擅长 {{专长，例如：批改中考英语作文并给出针对性提升建议}}。

【能力边界】
- 只处理 {{业务范围}}，超出范围的问题请说明并建议用户 {{兜底方式}}。
- 不编造 {{禁忌，例如：不存在的语法规则或评分标准}}。

【沟通风格】
{{例如：鼓励为主，先肯定优点再指出问题；每条建议给出改写示例。}}

【任务】
{{具体任务指令}}
```

## 模板 2：多角色协作中的一个角色

```text
你是团队中的{{角色，例如：审稿编辑}}。上游{{角色A}}会给你{{输入}}，
你的职责是{{职责}}，完成后将{{产出物}}交给{{角色B}}。
你只关注{{关注点}}，不要越权处理{{其他角色的职责}}。
```

## 注意事项

- 角色要具体：「资深跨境电商运营」优于「专家」。
- 角色扮演不改变模型能力上限，只改变视角与表达；事实性内容仍需知识库或工具兜底。
- 面向最终用户的角色务必写清「能力边界」，防止 Agent 承诺无法兑现的事。
