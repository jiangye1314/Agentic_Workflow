# 框架一：通用型提示词

> 结构：**背景 → 任务 → 要求 → 输出格式**。适合简单、一次性的任务。

## 模板 1：基础问答/写作

```text
【背景】
{{一句话说明你是谁、面向什么场景，例如：我在运营一个面向大学生的英语学习公众号。}}

【任务】
{{用动词开头的明确指令，例如：写一篇关于"如何坚持背单词"的推文。}}

【要求】
- {{约束1，例如：800 字以内}}
- {{约束2，例如：语气轻松，避免说教}}
- {{约束3，例如：给出 3 个可操作的方法}}

【输出格式】
{{例如：Markdown，含标题与小标题}}
```

## 模板 2：信息提取/转换

```text
【任务】从以下文本中提取 {{字段列表，例如：姓名、电话、预约时间}}。

【文本】
{{待处理文本}}

【输出格式】
仅输出 JSON，字段缺失时填 null，不要输出任何解释。
```

## 注意事项

- 任务指令尽量一句话说完；说不清就先拆步骤（改用任务执行型）。
- 「要求」每条可验证，避免「写得好一点」这类不可测描述。
- 输出格式是给下游程序/人看的契约，务必显式声明。
