## 书中提示词模板

第 7 章收录的填空式模板已整理到 [book-templates/](book-templates/)，可直接复制使用。

## 使用建议

1. 先按上表选框架，复制对应文件中的模板，替换 `{{变量}}` 槽位。
2. 模板中的「约束/边界」段落不要删除——它们是高风险场景的护栏。
3. 复杂应用通常是多个框架的组合：例如「角色扮演 + 知识库调用 + 任务执行」。
4. 提示词上线前用 [../templates/eval-dataset-template.jsonl](../templates/eval-dataset-template.jsonl) 建一个小评估集做回归。
