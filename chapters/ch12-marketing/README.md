# 第 12 章 智能化营销 · 导读 ★

> 四大场景方案卡：批量营销素材生成、智能客服对接、个性化商品推荐、数据分析。

## 本章要点

- 营销场景的共同主线：**内容生产的规模化** 与 **用户触达的个性化**。
- 推荐「云端 Agent 平台」起步（对应 12.1.3），快速验证后再考虑私有化。
- 所有对外内容必须有审核环节；AI 效果要用数据闭环验证（12.5）。

## 方案卡一：批量营销素材生成

| 环节 | 内容 |
| --- | --- |
| 痛点 | 多渠道多 SKU，文案/图文需求量大，人工产能不足 |
| 方案 | 商品信息结构化 → 按渠道模板批量生成图文素材 → 敏感词/品牌规范校验 → 人工抽检发布；直播文案按「商品卖点 × 直播话术结构」生成 |
| 工作流模式 | 并行化（多卖点/多渠道并发生成）+ 评估-优化（自检清单改写） |
| 提示词要点 | 任务执行型（输出契约=渠道×文案矩阵）+ 动态生成（商品槽位），见 [../../prompts/03-task-execution.md](../../prompts/03-task-execution.md)、[../../prompts/06-dynamic-generation.md](../../prompts/06-dynamic-generation.md) |
| 评估指标 | 素材采用率、人工修改幅度、单素材成本、违规拦截率 |
| 风险边界 | 广告法违禁词校验；不虚构功效 |
| 模板 | [marketing-content-pipeline.yaml](../../templates/marketing-content-pipeline.yaml) |

## 方案卡二：智能客服对接

| 环节 | 内容 |
| --- | --- |
| 痛点 | 咨询高峰排队、重复问题占用人力、服务时间受限 |
| 方案 | 从被动应答到主动服务：意图识别 → 知识库问答 → 订单/物流工具查询 → 满意度预测主动介入 → 无缝转人工（带上下文摘要） |
| 关键设计 | AI 应用嵌入业务流而非孤立 Bot：与工单、CRM、订单系统打通 |
| 提示词要点 | 角色扮演（品牌客服）+ 知识库调用 + 工具调用三框架组合，见 [../../prompts/](../../prompts/) |
| 评估指标 | 独立解决率、转人工率、平均响应时长、CSAT |
| 风险边界 | 退款/投诉等写操作与敏感场景必须转人工 |
| 模板 | [customer-service-agent.yaml](../../templates/customer-service-agent.yaml) |

## 方案卡三：个性化商品推荐

| 环节 | 内容 |
| --- | --- |
| 痛点 | 千人一面转化率低，人工选品难规模化 |
| 方案 | 电商数据收集与处理 → 构建用户画像（标签体系）→ 画像 × 商品库生成推荐理由 → 嵌入触达渠道 |
| 关键设计 | 画像标签可解释、可运营（业务人员能看懂并调整）；推荐理由经合规校验 |
| 评估指标 | 点击率、转化率、推荐多样性 |
| 风险边界 | 个人信息保护合规；用户画像数据最小化使用 |

## 方案卡四：数据分析与效果复盘

| 环节 | 内容 |
| --- | --- |
| 痛点 | AI 应用上线后「感觉有用」但无法量化 |
| 方案 | 搭建 AI 效果监测体系 → 关键指标数据跟踪 → 模拟 A/B 测试 → 定期复盘迭代 |
| 关键设计 | 每个 AI 应用上线即绑定北极星指标与护栏指标；A/B 分流在流量入口完成 |
| 评估指标 | 见第 6 章指标速查（[../ch06-agent-engineering/](../ch06-agent-engineering/)） |
