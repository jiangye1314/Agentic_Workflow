# 第 1 章 业务流程概述 · 导读

## 本章要点

- **业务流程**是一组将输入转化为对客户有价值输出的、相互关联的活动序列。关键词：输入、活动、输出、客户、价值。
- 三个分类维度：
  - **按价值创造**：核心流程（直接创造客户价值）/ 支持流程（保障核心流程）/ 管理流程（决策与管控）。
  - **按复杂度与结构化程度**：结构化（规则明确）→ 半结构化 → 非结构化（依赖判断）。AI 的甜区正从结构化向半结构化扩展。
  - **按执行方式**：人工 / 人机协同 / 自动化。
- AI 驱动的智能化转型方向：
  - 核心流程：从满足需求到**创造体验**；
  - 支持流程：从成本中心到**效率引擎**；
  - 管理流程：从经验决策到**科学决策**。

## 关键概念速查

| 概念 | 一句话理解 |
| --- | --- |
| 流程要素 | 谁（角色）在什么条件下（触发）做什么（活动）产出什么（交付物） |
| 核心流程 | 客户愿意为其结果付费的流程 |
| 支持流程 | 客户不直接感知，但出问题就会被感知 |
| 管理流程 | 决定资源往哪投、风险怎么控 |

## 动手练习

1. 画出你所在组织的一条核心流程，标注每个环节目前由「人 / 系统 / AI」中的谁执行。
2. 找出该流程中最耗时、最重复的 1~2 个环节，判断其结构化程度——这就是 AI 改造的候选切入点。
