# 第 9 章 办公自动化 · 导读

> 以多维表格等零代码工具构建高效的跨系统业务流。

## 本章要点

- 办公自动化的核心是**数据先结构化，流程才可能自动化**：多维表格把「表格 + 数据库 + 视图 + 自动化 + AI 字段」合一，是非技术团队的最佳入口。
- 典型组合：多维表格（数据中枢）+ 自动化规则（触发-动作）+ AI 字段/Agent（理解与生成）+ IM 通知。
- 边界：高频、重逻辑、需定制 UI 的场景应升级到编排引擎或 Agent 平台（第 7、8 章）。

## 常见场景速查

| 场景 | 搭建思路 | 资源 |
| --- | --- | --- |
| 内容选题与排期 | 表格为台账，AI 字段生成初稿，状态流转驱动通知 | [../../resources/feishu-bitable-practice.md](../../resources/feishu-bitable-practice.md) |
| 线索收集 → 跟进 | 表单收集 → 自动分配 → 超时提醒 | 同上 |
| 会议纪要 → 任务 | AI 提取行动项写入表格，责任人自动被提醒 | 同上 |

## 动手练习

1. 按实践文档搭一个「内容生产流水线」多维表格，至少包含 1 个 AI 字段与 1 条自动化规则。
2. 记录哪些环节仍然靠人肉搬运——它们就是接入编排引擎（第 8 章）的候选点。
