# 第 10 章 智能体全景 · 导读

> 智能体爆发期：从通用型到垂直型，从工作流走向自主行动。

## 本章要点

- **通用智能体**：以「一个对话框完成开放式任务」为目标，背后是长程规划 + 工具生态 + 沙箱环境。
- **垂直智能体**：在单一领域做深（领域知识 + 专业工具 + 合规边界），是当前商业化更清晰的方向。
- 判断一个 Agent 产品的三把尺：任务完成度（能否端到端交付）、可控性（过程可见可干预）、成本（单任务经济性）。
