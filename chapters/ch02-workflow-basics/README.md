# 第 2 章 认识工作流 · 导读

## 本章要点

- **工作流**是把业务蓝图变成可执行行动的机制：定义任务的顺序、参与者、规则与数据流转。
- **生命周期**：建模 → 部署 → 执行 → 监控 → 优化（闭环）。
- **四大核心系统**（人体类比）：
  - 流程编排 = 大脑（决定做什么、先后顺序）；
  - 任务调度 = 神经系统（把任务送达执行者）；
  - 数据流转 = 循环系统（上下文在各节点间传递）；
  - 状态追踪 = 记忆与感知（可观测、可回溯）。
- **演进三阶段**：人工与文档时代（1980s–1990s）→ 自动化与集成时代（2000s–2010s）→ 智能化与自主时代（2020s 至今）。
- 分类维度：触发方式、执行主体、结构灵活度；常见模式：顺序、分支、并行、循环、人工审批节点。

## 关键概念速查

| 概念 | 一句话理解 |
| --- | --- |
| 流程编排 | 用图/规则描述「谁在何时做什么」 |
| 任务调度 | 触发、排队、重试、超时的执行保障 |
| 数据流转 | 节点间传递的上下文与产物 |
| 状态追踪 | 每个实例「走到哪了、发生了什么」 |
