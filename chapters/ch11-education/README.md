# 第 11 章 教育行业：AI 驱动的个性化学习 · 导读 ★

> 三大场景方案卡：英语作文批改、个性化教学内容生成、个性化 AI 课堂互动。

## 本章要点

- 教育场景的共同主线：**标准化供给 → 个性化供给**，AI 让「千人千面」第一次具备成本可行性。
- 教育 = 高风险场景（未成年人、评价公平性）：所有方案必须保留教师复核与人工兜底。
- 落地节奏：先做「流程闭环的最小版本」，再用标注数据迭代个性化。

## 方案卡一：英语作文批改

| 环节 | 内容 |
| --- | --- |
| 痛点 | 批改耗时长、反馈滞后、评语千篇一律 |
| 方案 | 提交 → OCR/文本录入 → 多维度评分（词汇/语法/结构/内容）→ 生成针对性评语与改写示例 → 教师复核发布 |
| 工作流模式 | 链式（批改→校验→润色评语）+ 评估-优化（评语质量循环） |
| 提示词要点 | 角色扮演（资深教师）+ 任务执行（评分量规即输出契约），模板见 [../../prompts/02-role-play.md](../../prompts/02-role-play.md) 与 [../../prompts/03-task-execution.md](../../prompts/03-task-execution.md) |
| 个性化增强 | 积累学生历史作文的标注数据 → 识别个体薄弱点 → 评语与练习推荐个性化 |
| 评估指标 | 与教师评分的一致性、评语可执行率、教师复核修改率（越低越好） |
| 风险边界 | 分数仅供参考，正式评价由教师确认；学生数据脱敏 |
| 模板 | [education-tutor-agent.md](../../templates/education-tutor-agent.md) |

## 方案卡二：个性化教学内容生成

| 环节 | 内容 |
| --- | --- |
| 痛点 | 统一教材难以匹配班级差异，备课素材制作耗时 |
| 方案 | 搭建学科素材库 → 基础内容生成平台（教案/练习/课件初稿）→ 按学情数据个性化 → 教师反馈持续优化 |
| 关键构件 | 素材库（RAG 知识库）+ 动态生成提示词（按班级学情填槽位） |
| 提示词要点 | [../../prompts/06-dynamic-generation.md](../../prompts/06-dynamic-generation.md)：学情标签、难度档位作为槽位 |
| 评估指标 | 教师采用率、二次编辑幅度、学生测验表现变化 |
| 风险边界 | 内容需教师审定后使用；版权素材合规 |

## 方案卡三：个性化 AI 课堂互动

| 环节 | 内容 |
| --- | --- |
| 痛点 | 大班教学中互动机会不均，内向学生参与度低 |
| 方案 | AI 作为讨论参与者/引导者进入课堂：抛出问题、回应观点、组织协作任务，构建沉浸式与创造性学习环境 |
| 关键设计 | AI 定位为「助教与陪练」，不替代教师主导权；互动数据沉淀为学情画像 |
| 风险边界 | 课堂内容安全过滤；未成年人交互内容留痕可查 |

## 教育场景引入 AI 行动路线图（对应 11.5）

1. **试点**：选 1 个高频刚需场景（推荐作文批改），2~4 周跑出流程闭环。
2. **集成**：与现有教务/作业系统打通，避免师生多平台切换。
3. **扩展**：复制到内容生成与课堂互动，共用素材库与学情数据。
4. **治理**：建立数据脱敏、内容审定、家长知情同意的制度。

## 动手练习

1. 用评估集模板为作文批改建 10 条「作文 + 教师标杆评分」数据，测你搭建的批改 Agent 与教师评分的一致性。
2. 把 [education-tutor-agent.md](../../templates/education-tutor-agent.md) 改写成你所在学段的版本。
