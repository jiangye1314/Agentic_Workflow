# 第 3 章 智能体工作流概述 · 导读

## 本章要点

- **大语言模型（LLM）基础**：分类（通用/推理/多模态等）与能力边界（理解与生成强、事实性与时效性弱）——能力边界决定了为什么需要工具与知识库。
- **智能体（Agent）五维一体架构**：感知（输入）→ 规划（拆解与决策）→ 记忆（短期上下文 + 长期存储）→ 工具使用（行动）→ 反思（自我校验）。
- **智能体分类**：按自主性、按协作方式（单 Agent / 多 Agent）、按领域（通用 / 垂直）。
- **智能体工作流 vs 传统工作流**：

| 维度 | 传统工作流 | 智能体工作流 |
| --- | --- | --- |
| 路径 | 预定义、静态 | 可动态规划 |
| 节点能力 | 固定逻辑 | 具备理解与生成能力 |
| 异常处理 | 预设分支 | 可推理兜底（仍需护栏） |
| 适用任务 | 结构化、规则明确 | 半结构化、需判断 |
| 确定性 | 高 | 需评估与复核机制保障 |

## 关键概念速查

| 概念 | 一句话理解 |
| --- | --- |
| ReAct | 推理（Thought）与行动（Action）交替的循环 |
| 工具调用 | Agent 改变世界的「手」 |
| 记忆 | 会话内上下文 + 跨会话持久化 |
| 多智能体 | 用分工与协议解决单 Agent 上下文/能力瓶颈 |
