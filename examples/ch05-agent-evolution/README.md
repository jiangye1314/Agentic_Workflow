# 第 5 章配套伪代码：Agent 能力四级演进

> 整理自本书第 5 章（约 p104–107）的配套伪代码。

[agent_evolution.py](agent_evolution.py) 用四个递进的函数展示 Agent 架构的演进路径：

| 层级 | 函数 | 能力跃迁 |
| --- | --- | --- |
| L1 | `single_agent` | 单轮问答：提示词 → 回复 |
| L2 | `tool_augmented_agent` | 工具增强：先决策是否用工具，再生成 |
| L3 | `react_agent` | ReAct 循环：思考 → 行动 → 观察，多步迭代 |
| L4 | `multi_agent_system` | 多智能体：角色分工 + 共享工作空间 |

## 阅读要点

- 注意每一级**新增了什么构件**：L2 加了「决策 + 工具调用」，L3 加了「循环 + 观察回填」，L4 加了「角色 + 工作空间」。
- 对照第 5 章的核心主张：不要跳级——只有当上一级明显不够用时才升级架构。
- L3 的 `max_steps` 与 L4 的「评审不通过则修订」都是防止失控的护栏，对应第 6 章的工程实践。
