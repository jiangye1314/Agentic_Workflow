# Resources

本目录整理公开 GitHub 项目、官方示例和可复用实践模板，覆盖 Dify、FastGPT、n8n、RPA、飞书多维表格、ComfyUI、扣子/Coze 等方向。

## 使用边界

- 本目录只整理公开资料和原创结构化模板，不包含书稿派生案例。
- 所有第三方项目请以其原仓库许可证、官方文档和服务条款为准。
- 高风险业务场景必须保留权限控制、日志、人工复核和回滚机制。

## 推荐阅读顺序

1. 先看 `github-practice-index.md`，了解每个平台适合沉淀什么案例。
2. 再按平台读取对应 practice 文件，复制其中的模板结构。
3. 最后用 `platform-template-matrix.md` 决定案例放入 `examples/`、`templates/` 还是继续作为资源索引。
